## 2. 整體結論

前端資料呈現的安全性良好：
- 動態資料一律以 `esc()` 跳脫或以 `textContent` 插入，未發現 XSS。
- 第三方函式庫（three.js、N8AO、canvas-confetti）皆自行託管於 `vendor/`，不依賴外部 CDN，降低供應鏈風險。
- Git 歷史中沒有外洩的金鑰。
- 官方資料同步流程有自動驗證（`scripts/sync.py --verify`）。

原本的主要風險集中在兩個「接受任何人連線」的雲端端點：AI 代理與多人廣場。多人廣場已修補；AI 代理已於 2026-11-13 整個移除，網站目前不使用任何 API 金鑰。

## 5. 組織面待辦（無法由程式碼完成，依優先順序）

1. **帳號安全**：GitHub、Cloudflare 帳號全部啟用多因素驗證（MFA），只授權必要人員（Annex A 5.17、5.18、8.2）。
2. **GitHub 設定**：Settings → Code security 開啟 *Private vulnerability reporting*（`SECURITY.md` 指向此功能）、
   *Secret scanning* 與 *Push protection*；Settings → Branches 為 `main` 設定保護規則（需經 PR 才能合併），並將 `checks` 設為必要檢查。
3. **舊金鑰清理**：若 Cloudflare Pages 專案仍有 `GEMINI_API_KEY` 環境變數，予以刪除；並至 Google AI Studio 刪除該金鑰。
4. **Worker 設定**：若日後使用自訂網域，於 Worker 設定環境變數 `ALLOWED_ORIGINS=https://你的網域`；部署指令
   `cd workers/plaza-server` 後執行 `npx wrangler deploy`（Windows PowerShell 5.1 請改用 `npx.cmd -y wrangler deploy`）。
5. **事件應變程序**（Annex A 5.24–5.28）：廣場遭濫用時 → 可暫時於 Cloudflare 後台停用 `htl-island-plaza` Worker，
   前端會自動回退單機模式；網站內容異常時 → 於 Cloudflare Pages「Deployments」回滾至前一版；並記錄事件經過與改善措施。
6. 每季檢查第三方函式庫安全公告（R-16）；每年複審本文件，並將 `.well-known/security.txt` 的 `Expires` 延後一年（CI 會在到期前 30 天提醒）。
7. Dependabot 開出的 Actions 更新 PR：確認 CI 通過後再合併。

## 6. 測試紀錄（Annex A 8.29）

**自動化回歸測試**（`node --test tests/*.test.mjs`，CI 每次執行）：30 項，涵蓋 Origin 白名單、id／key 綁定、轉發白名單、聊天與封包速率限制、房間人數上限，以及離線角色（斷線保留、停留未滿 1 分鐘不保留、主動離開不保留、僅原 key 可接回、休眠後還原、6 小時到期、每房 100 筆上限）與私訊（只送收件者、寄件者不可偽造、離線不送達且不保存、速率限制、關閉私訊），以及星等只接受 1–5 整數、回訪玩家才收到 restored，與角色轉移（只能取一次、10 分鐘到期、格式檢查、IP 限速、≤ 200 筆、Origin 與方法限制）。
已做突變測試驗證有效性：分別移除 key 檢查、Origin 檢查、速率限制後，對應測試皆會失敗。

**多人廣場 Worker**（`wrangler dev` 本機執行、以腳本模擬攻擊者），20 項全部通過：
- 外站 Origin 被拒（403），Pages 預覽網域允許。
- 冒用他人 id：key 錯誤或未帶 key 皆回 409，原玩家不受影響；同 key 重新連線可正常取代舊連線。
- 封包內偽造 id／room 被伺服器覆寫；超大數值被限制；巢狀物件與未知欄位被移除；Unicode 雙向控制字元被移除；未知封包類型不轉發。
- key 從未出現在任何廣播內容中。
- 洪水攻擊：瞬間送出 300 個封包，只轉發 40 個；正常節奏（每 90 ms 一次，約 11/s）33/33 全數轉發，不受影響。

**瀏覽器實測**（Chromium，套用與正式環境相同的 CSP）：
- 首頁（中／英）、`timeline.html`、分享頁、404 頁，CSP 違規 0 件，3D 場景正常繪製。
- 真實前端與 Worker 連線：前端送出的 18 個外觀欄位完整通過白名單；對方加入與聊天正常顯示；
  聊天中的 `<b>XSS</b>` 以純文字呈現，未被當成 HTML。
- 網址帶 `?ws=wss://evil.example/ws` 時，前端忽略該伺服器並回到官方伺服器。
- 測試玩家以暱稱「謝文欽主任」加入廣場時，其他訪客畫面顯示為「訪客扮演・謝文欽主任」。
